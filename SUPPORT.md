# ALLIN Support

For help with ALLIN, report bugs, or request a feature, open an issue:

https://github.com/karam-G/universal-ai-ios/issues

Include your ALLIN app version, iOS version, and steps to reproduce a bug. Do not include passwords, private identifiers, or sensitive personal information.

Current release: 0.4.0
Current data model: local-first; user data is stored on the device and is not synced to an ALLIN server.
